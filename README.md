## 🔧 Troubleshooting

Even though RaceWave46 is designed to be problem-free, sometimes computers need a little extra help. Here's how to handle the most common hiccups.

### The game won't start.

- **Close other programs.** RaceWave46 needs a fair amount of memory. Try closing unused browser tabs or apps.
- **Check for antivirus warnings.** Some security software may flag new game files. If you see a warning, choose "Allow" or "Run Anyway."
- **Restart your computer.** It sounds simple, but a fresh start often fixes launch issues.

### The game looks blurry or the screen is stretched.

Press `Alt + Enter` while the game is running to toggle between fullscreen and windowed mode. In windowed mode, you can resize the window to your liking.

### The game runs slowly.

- **Lower the graphics settings.** From the main menu, go to **"Options"** → **"Graphics"** and set everything to "Low" or "Medium."
- **Make sure no other heavy applications are running** (such as video editors or browser streams).

### My controller isn't working.

- Ensure your controller is plugged in **before** starting the game.
- Go to **"Options"** → **"Controller"** and click **"Reset to Defaults."**
- If you're using a PlayStation controller, you may need to install DS4Windows (a free utility) to make it compatible.
